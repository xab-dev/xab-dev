## Ce que je fais

- **Cadrer un besoin IA** : partir du problème réel, choisir la stack adaptée, en exposer les limites, pas seulement les promesses.
- **Automatiser des process** : workflows et outils sur mesure, du script local à l'intégration d'assistants IA.
- **Piloter des agents de code** : développement guidé par des specs écrites avant le code, relecture humaine, audit de chaque diff.
- **Prévenir les mésusages** : sensibiliser équipes et particuliers au fonctionnement réel des LLM et à leurs failles.

## Ma méthode

1. **Cadrage & spécifications** écrits avant toute ligne de code
2. **Relecture humaine** des règles de sécurité et de logique
3. **Exécution ciblée** par un agent (Claude Code), fichier par fichier
4. **Audit de diff & validation Git** pour repérer immédiatement les régressions

Chaque étape est tracée : journal de session, dette numérotée, limites documentées. Rien n'est présenté comme fait sans avoir été vérifié.
